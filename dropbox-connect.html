Connect Dropbox

Makes a new Dropbox refresh token for the site without the app secret (PKCE). Everything happens in this browser: nothing is sent to the Creative Sound server.

1. App key

From dropbox.com/developers → App Console → your app → Settings.

2. Code

After you click Allow, Dropbox shows a code. Paste it here (it works for a few minutes, once).

3. Put it on Vercel

Vercel → Settings → Environment Variables: set DROPBOX_REFRESH_TOKEN to this value and DROPBOX_APP_KEY to the same app key, then Redeploy.

Then open /api/payouts/check while signed in as admin: "dropbox" should say "ok":true.
